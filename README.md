# 解锁全角色

提示：请勿在使用本插件的情况下进行抽卡，后果自负！！！
解锁未解锁的角色，但PVE等级固定为0级。推荐在PVP等无等级的模式中使用，请低调使用。

## 说明

- 客户端效果，不修改账号/服务器数据；
- 角色列表、详情、选人界面会显示为已拥有；
- 新解锁角色没有 PVE 等级，PVE 等级为 0；
- 联机模式仍可能受服务器校验限制；
- 请低调使用。

## 安装

```
mods/UnlockAllCharacters/
├─ UnlockAllCharacters.dll
└─ UnlockAllCharacters.json
```

PC / Android 通用，无需分平台。
